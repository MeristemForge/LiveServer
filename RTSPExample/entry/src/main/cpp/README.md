# Overview
LiveServer is an integrated solution that combines video capture, encoding, video processing and RTSP stream publishing. 
It simplifies the process of implementing RTSP streaming services on the OpenHarmony system, offering high performance and ease of use. 
The solution supports multi-camera input and stream multiplexing capabilities.

# Feature
- Support for Multiple Cameras
- Support for Stream Multiplexing
- Support for Static Watermark
- Support for RTP Over TCP and UDP
- Support for Hardware scaling, color space conversion, and video enhancement.

# Requirement
The system requires at least OpenHarmony version 5.0 or higher.
The compiler requires at least the C++20 standard.
